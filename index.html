1. What is a data type?

The identity of a value inside a cell or column.

A data type tells the software how to interpret a value: as a quantity, a label, a moment in time, or a yes/no flag. That interpretation controls which operations are allowed, how values are sorted and filtered, and how much memory they use.

Number

Can be summed, averaged, ranked and plotted on an axis.

Text

Can be counted, grouped and searched. Never summed.

Date / time

Sorts in time order and splits into year, quarter, month.

True / False

Drives conditions, flags and quick filters.

Golden rule: choose the type by what you will do with the column, not by how it looks. A phone number looks like a number, but you will never add two phone numbers together.

2. Data types in Excel

Select a type to see how it is stored, how it behaves and what to watch out for.

Format versus type

In Excel, Format Cells changes how a value is displayed, not what it is. A cell showing 15% still holds 0.15, and a cell formatted as Text can still hold something that looks like a number. When a calculation looks wrong, check the underlying value in the formula bar.

Useful functions for fixing types

FunctionUse it to
ISNUMBER(A2)Test whether a cell is a real number.
VALUE(A2)Convert number-like text into a number.
DATEVALUE(A2)Convert text such as “03/01/2025” into a date.
TEXT(A2,"000000")Display a number as text with leading zeros.
Data > Text to ColumnsBulk-convert a whole column of text numbers or dates.
Watch for the green triangle. It warns that a number is stored as text. Such cells are silently ignored by SUM and AVERAGE.

3. Data types in Power BI

Power BI is stricter than Excel: every column has exactly one type, and the type drives the whole model.

Where to set the type

Power Query (recommended)

Home > Transform data, select the column, then Transform > Data type. The change is recorded as a step and re-applied on every refresh.

Report / Model view

Select a column, then Column tools > Data type. Also lets you set the Data category (City, Country, URL) and the default Summarization (Sum, Average, Don’t summarize).

Tip: if dates import with day and month swapped, use Change Type > Using Locale and pick the locale of the source file.
